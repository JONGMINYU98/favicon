# 국기 그림

식품안전정보레터 메일과 대시보드에 들어가는 국기 그림입니다. [flagcdn](https://flagcdn.com) 국기 252개국을 복사해 두었습니다.
외부 국기 서비스가 바뀌거나 멈춰도 메일의 국기가 깨지지 않게 하려고 이 저장소에 둡니다.

- `w80/<코드>.png`: 가로 80px입니다. 메일에서는 가로 50px로 보입니다.
- `w160/<코드>.png`: 가로 160px로, 2배 해상도용입니다.
- 코드는 ISO 3166 두 글자 소문자입니다(예: 베트남 `vn`, 콜롬비아 `co`). EU는 `eu`, 코소보는 `xk`입니다.
- 메일에 넣는 주소는 `https://cdn.jsdelivr.net/gh/JONGMINYU98/favicon@main/flags/w80/<코드>.png`입니다.
- 기관명과 나라를 잇는 표는 대시보드 `Code.gs`의 `COUNTRY_CODE`에 있습니다. 새 나라를 추가할 때는 그 표에 한 줄만 넣으면 됩니다. 그림은 이미 여기 있습니다.
- 이미 보낸 메일도 이 주소를 쓰므로 **파일 이름은 바꾸거나 지우지 마세요.**
- 국기 그림의 출처는 flagcdn이며, 국기는 저작권 대상이 아닌 공공 상징입니다.
